## 🎬 How to Add Your Videos in the Video Section

1. Inside your project folder, there is an `assets/videos/` directory.
2. Put your recorded MP4 videos inside it, for example:
   - `assets/videos/video1.mp4` (Kulhad Pizza video)
   - `assets/videos/video2.mp4` (Cold coffee video)
   - `assets/videos/video3.mp4` (Cafe van ambience video)
3. Or you can embed your Instagram Reel or YouTube Shorts link directly in the video card `src`!

## 🖼️ How to Place Your Photos in `assets/images/`

Your photos have been referenced with clean relative paths:
- `assets/images/coffee-hub-hero.jpg` (The coffee van outdoor seating photo)
- `assets/images/kulhar-pizza-special.jpg` (Kulhad pizza banner)
- `assets/images/coffee-hub-combos.jpg` (Combos banner)
- `assets/images/coffee-hub-menu-card.jpg` (Full menu card)

Simply drop your JPG files into `assets/images/` with these names and they will display instantly across all pages!

## 🚀 How to Publish to GitHub (GitHub Pages)

### Step 1: Open Terminal / PowerShell in the folder
```powershell
cd "C:\Users\riman\.gemini\antigravity\scratch\digital-marketing-portfolio"
```

### Step 2: Initialize Git and Push
```powershell
git init
git add .
git commit -m "Launch official Coffee Hub website"
git branch -M main
git remote add origin https://github.com/YOUR_GITHUB_USERNAME/coffee-hub.git
git push -u origin main
```

### Step 3: Enable GitHub Pages (Free Live URL)
1. Go to your repository on [GitHub.com](https://github.com).
2. Click **Settings** (top tab) > **Pages** (left menu).
3. Under **Branch**, select `main` and `/ (root)`, then click **Save**.
4. In 60 seconds, your website will be live at:
   👉 `https://YOUR_GITHUB_USERNAME.github.io/coffee-hub/`
